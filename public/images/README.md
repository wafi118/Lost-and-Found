# Images

- `safefind-logo.png`: the SafeFind BUP logo (icon and wordmark) on a transparent background, used on light surfaces.
- `safefind-logo-dark.png`: a white version of the same mark, used on the dark theme. If the logo changes, regenerate both so they stay the same mark.
- `bup-campus.jpg`: a photo of the BUP campus, used once, in the card beside the headline on the home page (`views/home.ejs`). It is a roughly 1350x658 landscape JPEG shown with `object-fit: cover`; keep that ratio if you replace it.
- `favicon.svg`: the browser tab icon.
